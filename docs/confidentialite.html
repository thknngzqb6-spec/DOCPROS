Politique de confidentialité

Dernière mise à jour : 20 mars 2026

1. Introduction

La protection de vos données personnelles est une priorité pour DocPro. La présente politique de confidentialité décrit comment vos données sont traitées lors de l'utilisation du logiciel DocPro et du site getdocpro.fr.

2. Le logiciel DocPro

2.1. Principe fondamental : fonctionnement local

DocPro est un logiciel de bureau qui fonctionne intégralement en local sur votre ordinateur. C'est le principe fondateur de DocPro :

  • Aucune donnée n'est envoyée à des serveurs externes
  • Aucun compte en ligne n'est requis
  • Aucune connexion internet n'est nécessaire pour utiliser le logiciel
  • L'éditeur n'a accès à aucune de vos données

2.2. Données stockées localement

Les données suivantes sont stockées exclusivement sur votre ordinateur, dans une base de données SQLite locale :

  • Informations de votre entreprise (nom, SIRET, adresse, coordonnées bancaires)
  • Informations de vos clients (nom, adresse, SIRET, email)
  • Devis et factures créés
  • Paramètres et préférences du logiciel

2.3. Sécurité des données

Vos données étant stockées localement, leur sécurité dépend de la sécurité de votre ordinateur. Nous vous recommandons de :

  • Effectuer des sauvegardes régulières via la fonction intégrée de DocPro
  • Protéger votre ordinateur par un mot de passe
  • Maintenir votre système d'exploitation à jour

2.4. Suppression des données

Pour supprimer toutes vos données DocPro, il vous suffit de désinstaller le logiciel et de supprimer le dossier de données associé. Aucune donnée ne subsiste sur des serveurs distants.

3. Le site getdocpro.fr

3.1. Hébergement

Le site est hébergé par GitHub Pages (GitHub, Inc.). Les conditions de confidentialité de GitHub s'appliquent pour l'hébergement du site.

3.2. Données collectées par le site

Le site getdocpro.fr est un site statique qui ne collecte aucune donnée personnelle.

  • Pas de cookies de tracking
  • Pas d'outils d'analyse (Google Analytics, etc.)
  • Pas de formulaire de collecte de données
  • Pas de création de compte

3.3. Paiement via Stripe

Les paiements sont traités par Stripe (Stripe, Inc.), un prestataire de paiement sécurisé. Lors d'un achat, les données suivantes sont collectées par Stripe :

  • Adresse email
  • Informations de carte bancaire (traitées directement par Stripe — nous n'y avons pas accès)
  • Nom et adresse de facturation (si requis)

Stripe est certifié PCI-DSS. Vos données de paiement sont traitées conformément à la politique de confidentialité de Stripe. Nous recevons uniquement votre adresse email afin de vous envoyer la clé de licence.

3.4. Contact par email

Si vous nous contactez par email à contact@getdocpro.fr, nous conservons votre adresse email et le contenu de votre message uniquement pour répondre à votre demande. Ces données ne sont pas partagées avec des tiers.

4. Transfert de données

DocPro ne transfère aucune donnée à des tiers. Le logiciel ne contient aucun module de télémétrie, de tracking ou de publicité.

5. Vos droits (RGPD)

Étant donné que DocPro ne collecte aucune donnée personnelle (ni via le logiciel, ni via le site), les droits RGPD classiques (accès, rectification, suppression, portabilité) ne s'appliquent pas directement.

Vos données sont sous votre contrôle total :

  • Accès : toutes vos données sont visibles dans le logiciel
  • Rectification : vous pouvez modifier vos données à tout moment
  • Suppression : vous pouvez supprimer vos données en désinstallant le logiciel
  • Portabilité : la fonction de sauvegarde permet d'exporter toutes vos données

6. Modifications

Nous nous réservons le droit de modifier cette politique de confidentialité à tout moment. Les modifications seront publiées sur cette page avec la date de mise à jour.

7. Contact

Pour toute question relative à la confidentialité de vos données, vous pouvez nous contacter à : contact@getdocpro.fr
