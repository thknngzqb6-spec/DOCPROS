Questions fréquentes

DocPro est-il conforme à la législation française ?

Oui. DocPro inclut toutes les mentions légales obligatoires sur les factures : numéro SIRET, TVA, pénalités de retard, indemnité de recouvrement, et numérotation séquentielle conforme.

Mes données sont-elles en sécurité ?

Vos données sont stockées localement sur votre ordinateur dans une base de données SQLite. Rien n'est envoyé sur internet. Vous pouvez également faire des sauvegardes manuelles à tout moment.

Puis-je utiliser DocPro sur Mac ou Linux ?

Pour le moment, DocPro est disponible uniquement sur Windows 10 et 11. Les versions Mac et Linux sont prévues pour plus tard.

Y a-t-il un abonnement ou des frais mensuels ?

Non. DocPro fonctionne avec une licence unique. Vous payez une seule fois et utilisez le logiciel sans limite de durée, avec les mises à jour incluses.

Puis-je ajouter mon logo sur les factures ?

Oui. Dans les paramètres, vous pouvez importer votre logo qui apparaîtra sur tous vos devis et factures PDF.

Comment fonctionne la TVA pour les auto-entrepreneurs ?

DocPro gère l'exemption de TVA (article 293 B du CGI). Si vous n'êtes pas assujetti à la TVA, la mention légale est automatiquement ajoutée sur vos factures.

DocPro génère-t-il un fichier FEC ?

Oui. DocPro permet d'exporter le Fichier des Écritures Comptables (FEC) au format normé exigé par l'administration fiscale. Il suffit de choisir l'année dans les paramètres et de cliquer sur « Exporter FEC ». Le fichier généré contient les 18 colonnes réglementaires.

Comment mettre à jour DocPro ?

Les mises à jour sont gratuites et incluses avec votre licence. Téléchargez simplement la dernière version depuis le site et installez-la par-dessus votre installation existante. Vos données sont conservées automatiquement.

Puis-je transférer mes données sur un nouvel ordinateur ?

Oui. Utilisez la fonction « Sauvegarder » dans les paramètres pour exporter vos données. Installez DocPro sur votre nouvel ordinateur, puis utilisez « Restaurer » pour importer votre sauvegarde. Toutes vos factures, devis et clients seront récupérés.
